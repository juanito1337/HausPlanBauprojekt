# Nur lokale Daten – nicht automatisch in Git

Dieser Ordner ist bis auf diese README durch `.gitignore` ausgeschlossen. Hier können die separat bereitgestellten Originalarchive und bewusst gesicherte NX-Ausgabeordner liegen. Keine Dateien aus deiner funktionierenden Umgebung verschieben oder löschen.

Die .prt-Komponenten und Laufmanifeste müssen zusammen aufbewahrt werden. Kopieren allein aktualisiert NX-Referenzen nicht. Vor dem Öffnen einer verschobenen Baugruppe Pfadauflösung in NX prüfen. Keine Zugangsdaten hier oder anderswo in Git aufnehmen.

Codex Cloud sieht ignorierte Dateien nicht über den Git-Push. Lokaler Codex sieht Dateien nur, soweit seine Umgebung/Berechtigungen sie bereitstellen. Eine weitere Weitergabe privater Originaldaten ist bewusst zu entscheiden.
