# Künftige Abnahmetests

Mindestens abzudecken: keine Originaldatei-/Objektänderung; keine externen oder zwischen Zuständen gemeinsam bearbeitbaren Referenzen; identische Koordinaten/Maßstab; höchstens ein offener freigegebener Prüfabschnitt; Ecken-/Gründungs-/Leitungssperren; Grenzverletzungen bei Böschung, Verbau, Rückverankerung, Lager und Wegen; lückenlose Abfolge; Aushub/Wiederverfüllung/Restmengen konsistent; unbekannte Fundament-/Boden-/Wasserwerte bleiben unbekannt; fehlende Dateien/ungespeicherte Nutzerteile führen zu verständlichem Abbruch.

Diese Liste ist ein Prüfauftrag, keine vorhandene oder bestandene Testsuite. Echte NX-Kopien und Geometrie müssen separat in NX geprüft werden.
